## Usman Mushtaq Portfolio

Professional portfolio site showcasing AI/ML, data science, DevOps, and product leadership work.

Live site: https://umushtaq1990.github.io/DS_Portfolio/

## Highlights

- Multi-page layout: Home, About, Projects, Skills, Contact
- Clean, professional UI with consistent typography and spacing
- Lightweight, static site (no build step)
- Optional analytics hook (Plausible)

## Pages

- Home: quick positioning, stats, featured projects
- About: experience timeline, education, certifications, languages
- Projects: detailed project cards and outcomes
- Skills: streamlined capability list
- Contact: primary contact and social links

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- Google Fonts (Manrope, IBM Plex Mono)

## Project Structure

- index.html
- about.html
- projects.html
- skills.html
- contact.html
- styles/main.css
- scripts/main.js
- images/
- icons/

## Run Locally

Open index.html directly in a browser.

## Deploy

Recommended: GitHub Pages

1) Push the repo to GitHub.
2) Settings > Pages > Deploy from a branch.
3) Select main / (root).
4) Visit the provided URL.

## Analytics (Optional)

Uncomment the Plausible script in each HTML page and set your deployed domain:

<script defer data-domain="your-domain.com" src="https://plausible.io/js/script.js"></script>
